# Límite territorial de Las Tinajas — pendiente

Coloca aquí el archivo oficial `limite-tinajas.geojson` con el polígono de
límites territoriales de Las Tinajas (distrito de Dolega, Chiriquí), validado
por la Junta Comunal.

Después de agregarlo:
1. Abre `src/components/mapa/MapaTinajas.tsx`.
2. Cambia la constante `limiteDisponible` a `true`.
3. Verifica que el mapa cargue el polígono y el popup muestre el nombre correcto.

No se debe dibujar ni aproximar ningún límite mientras este archivo no exista.
